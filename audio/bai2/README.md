# Audio Bài 2

Cả phần Nghe (10 câu, cả Part I/II/III) dùng chung **1 file mp3 duy nhất**. Đặt file vào
đúng đường dẫn:

```
audio/bai2/listening.mp3
```

Trang `bai2.html` (ở thư mục gốc) đã có sẵn trình phát trỏ đúng vào file này — chỉ cần đặt
file mp3 vào đây với đúng tên `listening.mp3` là nghe được ngay, không cần sửa code.
