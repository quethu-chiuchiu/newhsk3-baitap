# Audio Bài 1

Cả phần Nghe (10 câu, cả Part I/II/III) dùng chung **1 file mp3 duy nhất**, giống băng nghe
thi thật HSK. Đặt file vào đúng đường dẫn:

```
audio/bai1/listening.mp3
```

Trang `bai1.html` (ở thư mục gốc) đã có sẵn trình phát trỏ đúng vào file này — chỉ cần đặt
file mp3 vào đây với đúng tên `listening.mp3` là nghe được ngay, không cần sửa code.

Các bài sau tạo thêm thư mục tương ứng, ví dụ `audio/bai2/listening.mp3`, `audio/bai3/listening.mp3`, ...
