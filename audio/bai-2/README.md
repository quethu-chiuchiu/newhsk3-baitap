# Audio Bài 2

Đặt file mp3 nghe của Bài 2 vào thư mục này, đặt tên theo đúng số thứ tự câu hỏi:

```
audio/bai-2/1.mp3   -> câu 1 (听力 Part I)
audio/bai-2/2.mp3   -> câu 2
audio/bai-2/3.mp3   -> câu 3
audio/bai-2/4.mp3   -> câu 4 (Part II)
...
audio/bai-2/10.mp3  -> câu 10 (Part III)
```

Trang `lessons/bai-2.html` đã có sẵn trình phát audio trỏ đúng vào các file này — chỉ cần
thêm file mp3 vào đây là nghe được ngay, không cần sửa code.
