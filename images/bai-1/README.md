# Ảnh Bài 1 — 听力 Part I (câu 1–3)

Phần Nghe Part I cho 4 lựa chọn hình A/B/C/D dùng chung cho cả 3 câu 1–3. Đặt đúng 4 ảnh
vào thư mục này với tên:

```
images/bai-1/A.jpg   -> hình A (người đứng ở ban công, mặc áo khoác)
images/bai-1/B.jpg   -> hình B (học sinh giơ tay trong lớp)
images/bai-1/C.jpg   -> hình C (một chiếc vali)
images/bai-1/D.jpg   -> hình D (nữ nhân viên đang nghe điện thoại)
```

Trang `lessons/bai-1.html` đã trỏ sẵn vào các file này — đặt đúng tên là hiện ảnh ngay,
không cần sửa code. Định dạng .jpg/.png/.webp đều được, chỉ cần giữ đúng tên file (đổi
đuôi thì sửa lại đường dẫn trong file HTML).
