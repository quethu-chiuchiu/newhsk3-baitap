# Ảnh Bài 1 — 听力 Part I (câu 1–3)

Phần Nghe Part I cho 4 lựa chọn hình A/B/C/D dùng chung cho cả 3 câu 1–3. Đặt đúng 4 ảnh
vào thư mục này với tên:

```
images/bai1/A.jpg   -> hình A (người đứng ở ban công, mặc áo khoác)
images/bai1/B.jpg   -> hình B (học sinh giơ tay trong lớp)
images/bai1/C.jpg   -> hình C (một chiếc vali)
images/bai1/D.jpg   -> hình D (nữ nhân viên đang nghe điện thoại)
```

Trang `bai1.html` (ở thư mục gốc) đã trỏ sẵn vào các file này — đặt đúng tên là hiện ảnh
ngay, không cần sửa code. Định dạng .jpg/.png/.webp đều được, chỉ cần giữ đúng tên file
(đổi đuôi thì sửa lại đường dẫn trong file HTML).

Kích thước khuyến nghị: tỉ lệ 4:3 (ngang), khoảng 480×360px, nén dưới ~150KB mỗi ảnh — vì
khung hiển thị chỉ cao ~100px và tự crop vừa khung (object-fit: cover), nên quan trọng nhất
là 4 ảnh A/B/C/D cùng tỉ lệ khung hình với nhau để không bị lệch trọng tâm khi crop.
